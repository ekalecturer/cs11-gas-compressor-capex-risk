The default simulation bounds are the sensitivity ranges, which is my assumption. Use it to see which inputs carry the risk, not as evidence about the real project. The paper reports no outcome after the decision.

Run your own simulation

Set the ranges, then run 5,000 trials. Capex is sampled uniform (as in the paper's Table 9) or normal with the same variance (Box-Muller). Contract life is uniform; debt share is triangular by inverse-transform sampling. The run also reports what happens if capex or contract life were fixed. The drivers are independent, so no copula is needed.

The lesson

A project that earns 7% of its capex in NPV has little room. In this reconstruction, capex explains 58% of the variance in NPV, contract life 39% and the debt mix 3%. Fixing capex cuts the modelled loss probability from about 9% to under 1%. The paper reports no post-decision outcome, so this is a decision rule, not a result.
